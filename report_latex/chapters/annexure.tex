\section{System Reproduction Procedure}
To reproduce the experimental testbed and launch the application locally, execute the following commands in Windows PowerShell:

\begin{lstlisting}[language=bash, caption={Complete reproduction and execution script}]
# 1. Clone repository
git clone https://github.com/thakurcoder/stock-pump-and-dump.git
cd stock-pump-and-dump

# 2. Setup Python virtual environment
python -m venv pumpwatch/venv
.\pumpwatch\venv\Scripts\Activate.ps1

# 3. Install dependencies in editable mode
pip install -e pumpwatch
pip install -r backend/requirements.txt

# 4. Install frontend npm dependencies
cd frontend
npm install
cd ..

# 5. Run automated test suites
pytest pumpwatch/tests -v
pytest backend/tests -v

# 6. Launch system via one-click script
.\dev.ps1
\end{lstlisting}
